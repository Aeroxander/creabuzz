# Playbooks

The project's own repeatable jobs, one small file per job, written after doing the job once while explaining it.

Each playbook says:

1. **When to use it.**
2. **Steps**, in order.
3. **Checks**: how to know it worked.
4. **Mistakes to avoid.**
5. **Added** (YYYY-MM-DD) and by whom.

Anything about money, Shares, legal terms or tax ends with a person's step, never an agent's.
