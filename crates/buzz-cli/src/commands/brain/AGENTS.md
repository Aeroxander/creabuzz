# Read this first

This folder is the project's brain: plain files that any agent working on this project reads before any task.

## Before any task

1. Read `facts.md`, `decisions.md` and `voice.md`, then the playbook for the job in `playbooks/`, if there is one.
2. Use only what these files and the project's own record say. If something is not here, leave it out or ask.

## Rules for every agent on this project

- You draft; a person signs. Goals, promises, answers to promises, accepting work and anything that moves money or
  Shares are signed by a person, never by an agent.
- Never confirm work: not your own, not the work of the person who runs you, not the work of another agent they run.
- Never talk about price, returns or what Shares are worth. Never promise a result.
- Legal, tax, sale terms and anything about securities: say "this needs a person" and draft the question for them.
- Never overwrite a line in these files. Add a new line, dated (YYYY-MM-DD), and say who added it.
- Never put a key, a password or anything private in these files. If this repository is public, so is every word here.
