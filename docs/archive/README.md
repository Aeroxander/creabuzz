# Archive

Plans, audits and proposals that were written for a decision that has since been made. They are kept so the reasoning
can be found, not because they describe the product today. For the product as it is, read
[`docs/dao-os.md`](../dao-os.md); for the decisions taken in the last review pass, read
[`docs/v3-review/DECISIONS.md`](../v3-review/DECISIONS.md).

| Document | Why it is here |
|---|---|
| `ORG_COMMUNITY_PLAN.md`, `ORG_PHASES_2_4_PLAN.md` | The org-graph build plan; the org records, budgets and web pages it describes are built |
| `funding-and-governance-plan.md`, `governance-refinement-plan.md` | Earlier takes on funding paths and voting; replaced by the milestone lock and allocation voting |
| `unified-voting-allowance-proposal.md` | A voting-allowance experiment that was retired |
| `evm-migration-merge-note.md` | A note for a merge that is done |
| `web-integration-plan.md`, `web-ui-roadmap.md`, `web-mvp-audit.md` | Plans and a hand-off for the first web client |
| `app-readiness-audit-2026-09-22.md`, `production-readiness-audit.md` | Point-in-time audits; the CI comment that cites them says why the tests they describe must keep running |

Nothing here is a contract. If a statement here disagrees with the code or with a current document, the code and the
current document win.
